Installation — cPanel

Follow this step-by-step guide to deploy Influner.com on a cPanel hosting environment. A full video walkthrough is also available below.

▶

How to Setup Node.js App on cPanel

Click to watch on YouTube
1

Upload Your Files

Log in to cPanel and navigate to File Manager. Upload the extracted application folder to your desired directory (e.g., public_html or a subdirectory).

2

Create a Node.js App

In cPanel, go to Software → Setup Node.js App. Click Create Application, select your Node.js version (20+), set the application root to your uploaded folder, and set the startup file to server.js (or as specified in your package).

3

Install Dependencies

In the Node.js App panel, click Run NPM Install. This will install all required packages automatically. Wait for the process to complete.

4

Start the Application

Click Start App in the Node.js App panel. Your application is now running. No environment variables need to be added manually.

5

Run the App Installer

Open your browser and navigate to yourdomain.com/setup. The built-in installer will automatically configure your database, environment, and admin account. Follow the on-screen steps to complete setup.

✅
You're Done!After completing the installer at /setup, your platform is fully live. No database import, no .env file editing required.

Installation — aaPanel

Prefer aaPanel? The process is equally straightforward. Watch the video guide below for a complete walkthrough.

▶

How to Setup Node.js App on aaPanel

Click to watch on YouTube
1

Upload Files via File Manager

Log in to aaPanel and use the File Manager or FTP to upload your application files to your server directory (e.g., /www/wwwroot/yourdomain.com).

2

Create a Node.js Project

In aaPanel, go to App Store → Node.js Version Manager (or use the Node.js project manager). Create a new project pointing to your application directory. Select Node.js 18+ and set the entry file.

3

Install Dependencies & Start

Run npm install from the terminal or the aaPanel Node.js interface. Once complete, start the application using the panel's start button or pm2.

4

Run the App Installer

Visit yourdomain.com/setup in your browser. The installer handles all database creation, configuration, and initial admin setup automatically.

💡
Pro TipUse PM2 (process manager) on aaPanel to keep your Node.js app running persistently even after server reboots. Install it with npm install -g pm2.

App Installer ( /setup )

Influner.com ships with a powerful built-in installer that eliminates all manual configuration. Once your Node.js app is running, simply visit the /setup route to get started.

🌐 Installer URL
Browser Address Bar
https://yourdomain.com/setup

The installer will walk you through the following steps automatically:

  • Database Setup — Creates and configures the database automatically. No SQL import needed.
  • Environment Configuration — Writes all necessary environment variables to the system. No manual .env editing.
  • Installer Lock — After successful installation, the /setup route is automatically disabled for security.
🔒
Security NoticeThe /setup route is automatically locked after first-time installation. If you need to re-run the installer, refer to the support documentation or contact our support team.

Frequently Asked Questions

🗄️ Do I need to import a database manually?

No. The built-in installer at yourdomain.com/setup handles all database creation and configuration automatically. There is no SQL file to import.

🔧 Do I need to configure environment variables?

No. You do not need to manually create or edit any .env file. All environment configuration is handled automatically by the /setup installer after your Node.js app is running.

📦 What hosting panels are supported?

Any hosting panel that supports Node.js application creation. This includes cPanel, aaPanel, and any VPS/server with Node.js 18+ installed. Video tutorials are provided for both cPanel and aaPanel.

💳 Which payment gateways are supported?

Payment gateways are configurable from the Admin Panel under Monetization → Payment Gateways. Supported gateways can be enabled and configured with your API keys directly from the dashboard.

🌍 Can I translate the platform into another language?

Yes. The platform includes a full Web Translation manager under Admin → Localization. You can translate every UI string without touching any code.

🤖 Can I use my own AI provider / API keys?

Yes. Under Admin → AI & Automation → AI Providers, you can configure your own API keys and select from supported AI backend providers.

🔒 Is the /setup route secure after installation?

Yes. The /setup route is automatically locked and disabled after the first successful installation. It cannot be accessed again without manual intervention, protecting your platform from unauthorized re-configuration.

📱 Which social platforms is the content optimized for?

Influner.com auto-optimizes content output for Instagram, TikTok, and YouTube Shorts. Each platform's aspect ratio, duration, and format requirements are handled automatically.

🎨 Can I white-label or rebrand the platform?

Yes. Under Admin → Appearance → Site Settings, you can update the platform name, logo, favicon, colors, and all branding elements to match your own brand identity.

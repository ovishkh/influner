## App Installer ( /setup )

Influner.com ships with a powerful built-in installer that eliminates all manual configuration. Once your Node.js app is running, simply visit the `/setup` route to get started.

🌐 Installer URL

Browser Address Bar

https://yourdomain.com/setup

The installer will walk you through the following steps automatically:

*   **Database Setup** — Creates and configures the database automatically. No SQL import needed.
*   **Environment Configuration** — Writes all necessary environment variables to the system. No manual `.env` editing.
*   **Installer Lock** — After successful installation, the `/setup` route is automatically disabled for security.

> **Note:**
> 🔒
> 
> **Security Notice**The `/setup` route is automatically locked after first-time installation. If you need to re-run the installer, refer to the support documentation or contact our support team.

## Requirements

Before installing, make sure your hosting environment meets the following requirements.

Requirement

Minimum

Notes

**Node.js**

v20+

LTS recommended. Available on cPanel & aaPanel.

**NPM**

v9+

Bundled with Node.js installation.

**Database**

Not Required

Auto-configured via the `/setup` installer.

**Environment Variables**

Not Required

Auto-configured via the `/setup` installer.

**Hosting Panel**

cPanel or aaPanel

Any panel that supports Node.js app creation.

**SSL Certificate**

Recommended

Required for payment gateways and social login.

**RAM**

512 MB+

1 GB+ recommended for production use.

> **Note:**
> ⚠️
> 
> **Important Note**You do _not_ need to manually import any database or set up `.env` files. The built-in installer at `yourdomain.com/setup` handles all of this automatically after your Node.js app is running.
